# BlueBank QA Project

A practical software testing portfolio project built around a fictional
digital banking platform called **BlueBank**.

## Project Purpose

This project is designed to:

-   Practice ISTQB CTFL concepts through hands-on testing
-   Demonstrate software testing analysis and design
-   Build a structured QA portfolio for GitHub
-   Practice Manual Testing before moving into API Testing, SQL, and
    Automation
-   Produce material for a software-testing case study
