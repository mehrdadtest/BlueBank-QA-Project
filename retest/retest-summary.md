## 4. Retest Metrics

Once Retesting begins, the following metrics can be calculated.

### Retest Pass Rate

```text id="j0p8ts"
Retest Pass Rate =
Passed Retests / Executed Retests × 100
```

### Retest Failure Rate

```text id="4x0g1u"
Retest Failure Rate =
Failed Retests / Executed Retests × 100
```

## 6. Current Conclusion

Retesting will begin after:

1. Test Execution identifies actual failures.
2. Bug Reports are created.
3. Fixes are delivered.
4. The relevant defects become Ready for Retest.

No Retest result is fabricated before actual execution.
